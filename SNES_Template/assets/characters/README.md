# Жители Черноречья

villagers-reference.png — исходный лист, предоставленный пользователем.
Оригинал сохранён без изменений; tools/import_npc_reference.py извлекает
игровые позы, удаляет связанный фон и посторонние фрагменты соседних кадров,
приводит тело к 24×36 внутри прежнего холста 32×48 и общей 15-цветной палитре OBJ.

В каждой колонке используются пары фронта, левого/правого профиля и спины.
Портреты верхней строки в игровые кадры не попадают. Для каждого из пяти
жителей получаются девять кадров: две фронтальные позы, короткий idle,
два левых, два правых и два задних кадра. Первый фронтальный кадр также формирует дальний силуэт 16×16. Код загрузки сохраняет две области
по 1024 B в OBJ VRAM; одновременно передаётся один новый кадр жителя.

Роли по порядку: Добрын (староста), Егор, Мирослава, Авдей, Тихон.
Данные SNES генерируются tools/build_npcs.py; atlas/preview находятся
в assets/generated/npc-sheet.png и npc-preview.png.
