# Предоставленные аудиоматериалы

`prototype/` — все 100 WAV из `chernorechye_audio_pack.zip`, без изменения.
README архива сохранён как описание происхождения и качества прототипа.

`selected/` — пять выбранных записей из
`drive-download-20261029T100900Z-1-001.zip`: факел, два вида шагов и две
фоновые музыкальные записи. Остальные записи второго архива не нужны
для перечисленных пользователем замен.

Интеграция описана в [AUDIO.md](../../docs/AUDIO.md). Сэмплы для SNES
и полные PCM для MSU-1 генерируются из этих исходников; отдельные шаги
вырезаются по пикам огибающей. SHA-256 и точные участки записаны в
`assets/generated/audio/manifest.json`.

Это предоставленные пользователем материалы; лицензия проекта не
перелицензирует их автоматически.
