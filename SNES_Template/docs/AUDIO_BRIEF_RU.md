# Звуковой заказ для текущей игры «Проклятие Черноречья»

Объём: пролог в НовГУ, деревня, лес, бой с лисами на Лунной просеке,
часовня, подземелье, воспоминания и три существующие концовки.
В списке звуки для действий и событий, которые уже есть в игре.
Это исходный заказ до импорта записей. Текущее подключение эффектов,
окружения и музыки из двух предоставленных архивов описано в [AUDIO.md](AUDIO.md).

## 1. Интерфейс — 7 позиций

| Имя | Что требуется / применение |
|---|---|
| ui_move | Короткий мягкий щелчок выбора пункта меню, ответа, чаши или колокола |
| ui_confirm | Подтверждение, продолжение диалога, успешная калибровка Scope |
| ui_cancel | Назад, отмена выбора, выход из паузы |
| ui_error | Недоступное действие, неправильный порядок загадки, отсутствие стрел или защитных откликов серебра; один универсальный короткий отказ |
| journal_handle | Открыть и закрыть записи Кирилла — два отдельных исполнения |
| journal_page | Перелистывание страницы журнала |
| evidence_added | Найдено новое письменное свидетельство / важная запись |

Не делать отдельные звуки каждой кнопке. Повторное чтение той же записи
не должно снова звучать как новая находка.

## 2. Движение, свет и припасы — 6 позиций

| Имя | Что требуется / применение |
|---|---|
| step_ground | Шаги по земле, траве и лесной подстилке; три варианта, один чуть более шуршащий для леса |
| step_wood | Шаги по деревянному настилу и полу; три варианта |
| step_stone | Шаги по камню в часовне и подземелье; три варианта |
| step_university | Шаги/бег по полу спортзала и коридора НовГУ; три варианта |
| torch_toggle | Зажигание и тушение факела — два отдельных файла; тушение пригодно также для окончания смолы |
| supplies_refill | Короткое пополнение смолы и стрел: сосуд, жидкость, колчан |

Фон горящего факела указан в разделе окружения. Отдельные файлы для
каждого направления движения и каждого NPC не нужны.

## 3. Герой и лук — 9 позиций

| Имя | Что требуется / применение |
|---|---|
| bow_draw | Натяжение тетивы: короткое начало, пригодный к удержанию участок |
| bow_ready | Тихий ясный сигнал полного натяжения; подходит также для уведомления о смене фазы суток |
| bow_release | Щелчок тетивы и выпуск стрелы; слабый и сильный варианты, без длинного хвоста |
| arrow_hit_surface | Попадание в деревянное и каменное препятствие — два исполнения |
| arrow_hit_enemy | Сухое попадание в противника; два варианта |
| player_shove | Взмах, одежда и короткий контакт при толчке |
| player_hurt | Глухой удар и сдержанный мужской выдох; два варианта |
| player_heartbeat | Телесное сердцебиение страха; один короткий цикл, повтор задаёт игра |
| player_defeat | Срыв от страха и возврат к порогу; подходит поражению на просеке. Без смертельного крика, герой может продолжить |

Лук остаётся луком при любом контроллере. Выстрел должен читаться при
частом повторении в бою с лисами. Звук готовности не должен перекрывать
предупреждения противников. Отдельная «перезарядка ружья» не нужна.

## 4. Тени и ползуны — 4 позиции

| Имя | Что требуется / применение |
|---|---|
| shade_warning | Короткий неестественный вдох/шорох перед атакой тени |
| crawler_warning | Более низкий скрежет/хрип перед броском ползуна; отличается от тени |
| enemy_lunge | Короткий звук резкого броска; допускает изменение высоты для двух типов врагов |
| enemy_dissolve | Рассеивание побеждённой нечисти; два родственных исполнения |

Для ранения достаточно arrow_hit_enemy. Предупреждения начинаются до удара
и различимы на фоне окружения. Отдельные постоянные голоса каждого врага не нужны.

## 5. Лисы и волны на просеке — 7 позиций

| Имя | Что требуется / применение |
|---|---|
| fox_warning | Лиса приседает и фиксирует полосу атаки: хриплое лисье тявканье/рык, два варианта |
| fox_charge | Начало броска: резкий выдох и короткий лисий звук |
| fox_hurt | Короткий вскрик при попадании; два варианта |
| fox_retreat | Разворот и уход в лес после промаха: отдаляющийся звук и шорох |
| fox_dissolve | Исчезновение подстреленной лисы Сердца: короткий магический хвост |
| wave_start | Предупреждение о начале следующей волны |
| wave_clear | Передышка после волны; короткая версия и завершённая версия для победы над всей стаей |

Не делать отдельные наборы для трёх типов поведения лис. Для лап можно
переиспользовать короткие варианты step_ground. Отступление звучит иначе,
чем поражение. Поражение героя использует player_defeat.
Лисы должны узнаваемо тявкать, без басового собачьего лая.

## 6. Загадки, серебро и память — 8 позиций

| Имя | Что требуется / применение |
|---|---|
| magic_touch | Три связанных отклика: ПАМЯТЬ/ИМЯ/СВЕТ. Семейство переиспользуется для лесных знаков ВОДА/РОД/СВЕТ, чаш и замыкания узлов; дать три отдельных файла |
| forest_path_open | Магический отклик, когда лесные знаки открыли тропу к просеке |
| silver_flash | Защитная вспышка серебра, отбрасывающая нечисть |
| bell | Три отчётливо различающихся колокола: левый, правый, средний; три отдельных удара |
| memory_reveal | Факел проявил след, открывается воспоминание |
| memory_restored | Всеволод вспомнил весь день после чтения трёх свидетельств; короткое эмоциональное разрешение |
| node_charge | Тихое нарастание при зарядке узла факелом; участок удержания или короткая петля |
| ritual_ready | Все три узла готовы; финальная сделка ещё не совершена |

Ошибки и пустое серебро используют ui_error. Успех колоколов может завершаться
тем же семейством, что memory_reveal. Порядок колоколов: левый → правый → средний.
ritual_ready не должен звучать как окончательная победа: после него ещё есть выбор.

## 7. Предметы и физические события — 8 позиций

| Имя | Что требуется / применение |
|---|---|
| coin_ring | Физический металлический звон монетки; два варианта |
| coin_answer | Знакомый звон с неестественным отголоском: ответ из подвала и родство серебра с монеткой |
| door_handle | Открыть и закрыть скрипящую дверь; закрытие с коротким акцентом засова подходит решению запереть Егора — два файла |
| rope_loosen | Ослабление узла/пут у Егора |
| rope_strain | Натянутый мокрый канат держит лодку, треск волокон |
| rope_cut | Нож перерезает канат, резкий обрыв натяжения |
| stone_slab | Каменная плита сдвигается, открывая лестницу под часовню |
| boat_creak | Скрип и деформация лодки в воспоминании |

Взятие серебра использует coin_ring/coin_answer. Чтение бересты и досок
использует evidence_added, без отдельного эффекта для каждого документа.

## 8. Сюжет и финал — 6 позиций

| Имя | Что требуется / применение |
|---|---|
| river_splash | Вода захлёстывает борт / человек остаётся в реке; два варианта |
| memory_cry | Короткий женский вскрик Мирославы, обрывающийся в первом видении; без слов |
| black_heart_pulse | Глухой каменный пульс Чёрного Сердца; отличается от телесного сердцебиения героя |
| heart_sealed | Сердце закрывается, давление и пульсация отпускают |
| memory_taken | Сердце забирает память при сделке: знакомые звуки распадаются и уходят в тишину |
| world_crossing | Переход между НовГУ и Черноречьем: два родственных исполнения — вход и возвращение домой |

Воспоминание о лодке собирается из river, boat_creak, rope_strain,
rope_cut, river_splash и memory_cry. Не сводить всю сцену в один длинный
файл: страницы диалога перелистывает игрок. Изменение мира при переходе
должно роднить звон монетки и шум реки.

## 9. Окружение — 8 общих слоёв

| Имя | Что требуется / где используется |
|---|---|
| torch_fire | Негромкое горение и треск факела; меню и исследование |
| wind | Мягкий ветер: открытая деревня, лес и Лунная просека |
| leaves | Шелест елей/листвы для леса и края просеки |
| village_life | Редкие негромкие птицы и бытовые скрипы для деревни при свете |
| night | Редкие ночные насекомые и шорохи; без непрерывного воя |
| river | Течение и плеск: брод, аномалия за дверью НовГУ, лодочное воспоминание |
| stone_room | Глухой воздух и редкие капли для подземелья; тихая версия подходит часовне |
| university_room | Воздух пустого здания и слабый электрический гул: спортзал, коридор и подвал |

Для ветра, воды, огня и гула нужны бесшовные короткие петли.
Редкие птицы, капли и скрипы лучше отдать отдельно от постоянного слоя.
Общие слои будут смешиваться по месту; отдельные тяжёлые записи для
каждой карты и каждого времени суток не требуются.
Во время боя фон тише предупреждений лис. В плохой концовке деревня замолкает.

## 10. Музыка — отдельная часть заказа, 8 тем

| Имя | Где и какое настроение |
|---|---|
| music_title | Главное меню: основной мотив тайны Черноречья; петля 60–90 с |
| music_explore | Деревня и лес: сдержанная тревога с человеческим теплом; общий мотив, петля 60–90 с |
| music_ambush | Бой с лисами: ритм и напряжение, слышны предупреждения; петля 45–75 с |
| music_chapel_crypt | Часовня и подземелье: печаль и давление Сердца; общий мотив, петля 60–90 с |
| music_final | Финальный разговор и выбор; без преждевременного разрешения, петля 40–60 с |
| music_ending_guardian | «Хранитель»: Кирилл остаётся помогать Всеволоду; тихая стойкость, 25–45 с |
| music_ending_silent | «Тихая деревня»: утрата памяти, исчезновение привычной мелодии, 20–40 с |
| music_ending_witnesses | «Два свидетеля»: память вернулась, Кирилл возвращается домой, 30–50 с |

Для пролога достаточно фона НовГУ, монетки, реки и перехода;
отдельную тему ему заказывать не обязательно. Титры используют тему меню
или соответствующей концовки. Это музыкальный заказ для имеющихся сцен,
а не перечень уже подключённых треков.

## Сдача и формат

- 55 позиций эффектов, 8 слоёв окружения, 8 музыкальных тем.
  Позиция с перечисленными вариантами предполагает несколько отдельных файлов.
- Эффекты WAV PCM, моно, 44,1/48 kHz, 16/24 bit. Это мастер-исходники;
  уменьшение частоты и конвертацию в BRR выполним при интеграции.
- Короткие игровые эффекты обычно 0,05–0,40 с; магические события 0,3–1,5 с;
  переходы и финальные эффекты до 2–3 с. Длительности ориентировочные.
- Без тишины в начале, клиппинга и лишнего длинного реверберационного хвоста.
  Сухие исходники обязательны; обработанные примеры полезны отдельно.
- Петли ориентировочно 1–4 с; указать начало/конец петли. Их окончательный
  размер и одновременное число слоёв определяются бюджетом SNES.
- Имена латиницей, варианты с суффиксом: fox_warning_01.wav, fox_warning_02.wav.
- Музыка: WAV для согласования плюс проект. Для SNES желательно `.it`
  с короткими инструментальными сэмплами и небольшой аранжировкой.
  Если музыка пишется в DAW — также MIDI и отдельные партии для адаптации.
- Полная озвучка диалогов, самостоятельные темы NPC и звуки отсутствующих
  механик в этот заказ не входят. Из голосов достаточно короткого выдоха
  героя и вскрика в воспоминании.

## Состояние до импорта архивов

heartbeat → player_heartbeat; latch → переключение факела;
seal → смена карты/узла; chime → готовность лука/смена суток;
bow → выстрел; impact → попадание/победа; attack → подготовка атаки;
shove → толчок; hurt → ранение героя.
Остальная таблица описывает производство и последующее подключение звука
для существующих игровых событий, а не готовую функциональность аудиодрайвера.
