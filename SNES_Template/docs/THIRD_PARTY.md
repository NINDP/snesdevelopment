# Third-party notices

## PVSnesLib 4.6.0

The ROM links the SNES runtime from PVSnesLib. The SNESMOD SPC700 source
in `Data/audio/spc700.asm` is a modified version: Chernorechye adds command
0C for an independent channel volume, used to mute the torch without
reloading music. `Data/audio_boot.asm` adapts the PVSnesLib boot routine.
Original SNESMOD authors are Mukunda Johnson and KungFuFurby; the WLA-DX
port is by the PVSnesLib team. SDK binaries
are downloaded separately and are not included in this source package.

## Novgu-Biohazard artwork

The gym, Kirill sprites and animated coin frames in assets/cinematics come
from the local Novgu-Biohazard project. Its MIT license is preserved verbatim
in assets/cinematics/Novgu-Biohazard.LICENSE. New cinematic and location
artwork was generated with the built-in image_gen tool; the prompts and
reference roles are recorded in assets/cinematics/README.md.
