# Архитектура

## Runtime

Ядро Game — фиксированная 52-байтная структура. Режимы: заставка, меню,
диалог, исследование, выбор, чаши, журнал, пауза, концовка, помощь, сведения, колокола.
Флаги истории занимают 16 бит; свидетельства — три бита отдельного байта.
Никакой кучи, float, рекурсивного обхода мира или программного 3D.

Clock выдаёт 60 логических тиков: NTSC 60 кадров → 60 тиков, PAL 50 → 60.
Короткие lag-переходы догоняются максимум четырьмя экранными кадрами.
Фронт кнопки применяется один раз. Это не гарантия отрисовки 60 FPS.

## PPU

| Адрес в словах VRAM | Назначение |
|---|---|
| 0x0000 | BG1 тайлы текущего фона, максимум 512 × 32 байта |
| 0x4000 | BG1 карта 32×32, 2048 байт |
| 0x5000 | BG3 CP1251-шрифт, панель и калибровочная мишень |
| 0x5C00 | BG3 карта 32×32, WRAM-кеш видимых 32×28 |
| 0x6000 | OBJ 128×128 4bpp, 8192 байта |

Mode 1, BG3 высокий приоритет. CGRAM фон 0..15, текст 28..31,
OBJ 128..143. Нулевой фон чёрный. CP1251 0..255 не меняются:
панель — tile 256, калибровка — 257..260.

Смена фона — forced blank. Карта текста загружается по DMA только после
изменения UI; передаются только 1792 видимых байта. Восемь направлений конуса предварительно рассчитаны генератором.
Одинаковые spans используются в проверке видимости, поиске предметов и PPU.

## Фонарь

Канал HDMA 6 пишет WH0/WH1. Таблица содержит верхние 24 полных строки,
42 полосы по 4 строки и нижние 32 строки интерфейса. Два буфера по 133 байта:
строим неактивный, публикуем только готовый, переключаем на VBlank.
BG1 и OBJ скрываются вне окна; BG3 остаётся читаемым. При выключении
левая граница 255, правая 0: окно пустое. Даже пауза не раскрывает тёмный мир.

Таблицы размещены в WRAM банка 7E; генератор символов и ROM тесты помогают
проверять расположение после расширения. Не занимать канал 6 обычным DMA.

## Ввод и звук

Адаптер владеет nmi_handler и читает геймпад/Scope на каждом VBlank.
Очередь: четыре слота, полезная ёмкость три. ISR пишет голову, main хвост;
публикация 8-битного индекса после завершения записи. Переполнение
отбрасывает новый пакет, не растит память. Не добавлять второй nmiSet.

Три BRR эффекта — heartbeat, latch, seal. SPC-таблица подключается явно к
первому элементу массива, индексы 0/1/2. spcProcess обслуживается в цикле.
Нет музыки и озвучки; WAV приложены для дальнейшей работы звукорежиссёра.

## Расширение

- Сценарист: JSON, пять строк по 30 знаков; порядок DialogueId согласовать с генератором.
- Программист ядра: game.c и тесты решений, пазлов, восстановления.
- Программист платформы: видео, HDMA, ввод, SPC и ROM тест.
- Дизайнер: процедурные карты/атлас или замена их тайлов; соблюдать VRAM и hotspot coordinates.
- Звукорежиссёр: WAV/BRR, затем музыка; увеличивать SPC sound region по реальному размеру.

Перед релизом нужны реальная SNES, CRT/Scope, человеческое прохождение
и macOS-сборка. Код и автоматические проверки не заменяют эти этапы.


Пути адаптации: Data/core, Data/platform, Data/gameState.c. Адреса и размеры
буферов вынесены в Data/include/video_layout.h. Измерения и ограничения
переноса — [PORTING.md](PORTING.md).
