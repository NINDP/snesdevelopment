# Nabla — Тени универа: Проклятие Черноречья

Хоррор для SNES с псевдо‑3D на Mode 7. Продолжение победной концовки `Novgu-Biohazard`:
Кирилл спускается в подвал НовГУ и попадает в тело Всеволода в Черноречье,
1193 год. Нужно вернуть хозяину тела память и найти путь домой.

Текущий сценарий содержит **79 экранов в 44 группах сцен**. Во вступлении события показаны
спортзалом из первой части, проходом по коридору к лестнице, подвалом
и отражением у реки. Между спортзалом и лестницей герой управляется
крестовиной: бег слева направо, семь кадров анимации, плавная прокрутка.
Заставка NABLA TEAM с бронзовым знаком ∇ оформлена в стиле главного меню:
ночной пейзаж, тёмная плашка и янтарные акценты. Искры от факела собираются
в знак ∇, затем появляются надписи по центру; заставка плавно гаснет.
Меню повторяет композицию
первой игры с тёмным городом, тёплым светом и пунктами слева.
Факел в главном меню горит: пламя колышется, искры поднимаются и затухают.
В исследовании постоянно видны игровые часы, запас факела и страх. Нижняя
панель отделяет показатели от подсказок и состояния лука; текст больше не
попадает на границу видеорежимов. Журнал — отдельный экран с бронзовой рамкой,
иконками, красными шкалами и крупными часами. Стрелки влево/вправо переключают
обзор цели и полные записи; B возвращает в игру. Снаряжение и улики сохранены.
Прокрутка панорамы больше не делит DMA7 с библиотечной загрузкой спрайтов;
регрессия Mesen проверяет владение каналами, переходы UI и ночную сцену.
Переработаны деревня и лес: связные дороги и двор, брод, высокие ели,
избы 64×64 и колодец. Поверхности используют отдельные материалы травы,
земли, мокрого берега, дерева и камня. Перспектива остаётся на Mode 7;
крупные объекты имеют несколько заранее подготовленных размеров по глубине.
Дворы дополнены огородами, дровами, бочками и корзинами. За домами и
деревьями видны отдельные панорамы: дальние крыши, поля, холмы и лес
в дымке с тремя скоростями прокрутки. Ночью дальний фон исчезает.
Добрын, Егор, Мирослава, Авдей и Тихон получили отдельные фигуры 24×36,
лица, одежду, дыхание и моргание. Персонажи заменены по предоставленному
спрайт-листу: есть фронт, оба профиля и спина, жители поворачиваются к герою. Плотные сцены деревни и леса дают
30 FPS NTSC / 25 FPS PAL; симуляция работает в 60 тактов/с.
Сохранены загадки, четыре решения и три концовки. Ранние решения можно
исправить повторным разговором. Плохой финал требует явной сделки с Сердцем;
три письменных свидетельства открывают возвращение Кирилла домой.

## Запуск

Скачай артефакт **chernorechye-snes** из успешной проверки GitHub Actions:
он содержит `chernorechye.sfc`, SHA-256, исходники, сценарий и кадры PPU.
Ветка разработки — `port/chernorechye-snes`. Геймпад — порт 1, Scope — порт 2.
После локальной сборки ROM находится прямо в этой папке.

## Сборка

Нужны Python 3, make, Pillow, NumPy и PVSnesLib **4.6.0**.
Игровой шрифт — собственный пиксельный ASCII/CP1251: системные TTF и
`SK_FONT` для сборки больше не нужны. Упаковка превью использует DejaVu Sans.

```sh
cd SNES_Template
python3 -m pip install -r requirements.txt
sh tools/get_sdk.sh
export PVSNESLIB_HOME="$PWD/third_party/pvsneslib"
make
```

Если SDK уже установлен, достаточно задать `PVSNESLIB_HOME` и вызвать `make`.
Пути к эмулятору и конвертеру в домашней папке не зашиты в Makefile.
Графика / шрифт / BRR и CP1251-текст генерируются инструментами проекта.
Сторонние инструменты в корне репозитория можно использовать для авторинга;
они не являются исполняемым кодом картриджа.

Сборка явно перечисляет C/ASM-модули, отслеживает заголовки до C → .ps,
отклоняет повторяющиеся объекты и проверяет контрольную сумму ROM.
ROM и символы публикуются после успешной линковки; тесты дополнительно
проверяют их хеши по `build/link_manifest.json`.

## Управление

| Действие | Геймпад |
|---|---|
| Идти | Крестовина |
| Включить / выключить свет | X |
| Осмотреть / выбрать / продолжить | A |
| Записи, цель и собранные воспоминания | Y |
| Серебро в исследовании / назад в меню | B |
| Пауза / возврат к порогу | START |
| Достать / убрать лук | L |
| Оттолкнуть врага перед собой | R |
| Шаг с луком / прицеливание при удержании A | Крестовина |
| Натянуть / выстрелить | Держать A / отпустить A |

Факел даёт круговой свет с ярким центром, тёплым затемнённым краем
и лёгким мерцанием. В исследовании круг остаётся круглым на экране,
следуя за героем и факелом. Ночью и в закрытых помещениях за его пределами
полностью чёрные земля, персонажи и предметы. Без факела там ничего
не видно; диалоги, журнал и пауза не раскрывают скрытые участки.

На улице действует [смена суток](docs/DAY_CYCLE.md): полный цикл длится
12 минут 48 секунд активного исследования. Начало — 16:00; с 18:00
солнце постепенно гаснет, в 20:00 наступает ночь, рассвет — с 05:00 до 07:00.
Днём можно беречь смолу; к сумеркам возвращаются лесные тени.
Часовня с заколоченными окнами и подземелье остаются тёмными всегда.
Время и номер суток видны в журнале; диалоги, загадки, журнал и пауза
останавливают часы. Следы памяти по-прежнему требуют огня даже днём.

Факел держится в левой руке. Есть восемь кадров пламени, локальное свечение
и пять искр с дрейфом и затуханием. Круг света следует за огнём при повороте.
Всеволод — спрайт 32×48: четыре направления, по две позы ожидания
и шесть фаз шага. У лука есть восемь поз на направление:
подготовка, половина и полное натяжение, отпускание, два шага, толчок и отдача.
С опущенной тетивой можно идти вполскорости; удержание A останавливает ноги
и переводит крестовину в прицеливание. Во время стрельбы
факел ставится у ног. Лук доступен сразу, колчан вмещает 24 стрелы; сосуды
пополняют и смолу, и стрелы. Панель показывает натяжение и перезарядку. Враги предупреждают о рывке
вспышкой; стрелой или толчком можно сбить атаку. Подробнее —
[боевая система](docs/COMBAT.md).

С каждой новой ночью врагов становится больше: до четырёх в лесу и подземелье.
Они ускоряются, позже появляются живучие ползуны, которые пробираются через
свет факела. Часовня остаётся убежищем. Ночи и победы видны в журнале.
Отдельный спрайт-лист — assets/generated/torch-sheet.png.
Для осмотра предмет должен быть рядом и находиться в освещённой области.
Подпись «A: …» показывает цель перед героем. Условия и результаты действий
видны сразу внизу экрана: порядок знаков, заряд узла, нужные разговоры.
При подходе сбоку выбор учитывает направление взгляда, а повторный разговор
с Мирославой показывает принятое решение. Смола пополняется у сосудов. Страх возвращает к порогу,
сохраняя решения и находки. Диалоги, меню и головоломки смолу не тратят.

След памяти: держать факел рядом до **45**, затем A. Узел печати: светить до **60**,
затем A. Серебро даёт **три** защитных отклика: отбрасывает тень и снижает страх;
смола и контрольная точка заряды не восстанавливают. Колокола в часовне имеют
отдельную последовательность; объяснение встроено в диалог Авдея.

Scope: первый FIRE/CURSOR или SELECT открывает калибровку. Отпусти кнопку,
затем FIRE по центру белой мишени; CURSOR подтверждает. FIRE задаёт движение / осмотр, CURSOR зажигает факел,
TURBO удерживает героя на месте. Выключи TURBO, чтобы идти.
В стойке лука FIRE натягивает тетиву и выпускает стрелу в выбранную цель.
Лук достаётся кнопкой L геймпада; журнал и серебро используют Y / B. Scope требует совместимый CRT;
реальное устройство пока не проверено. Подробности и назначения мыши
для установленного bsnes — [SCOPE.md](docs/SCOPE.md).

## Код и контент

| Путь | Назначение |
|---|---|
| main.c | Вход через GameStart / GameUpdate / GameDraw |
| Data/gameState.c | VBlank, ввод и связь с жизненным циклом шаблона |
| Data/core/ | Переносимое ядро, геометрия света, PAL/NTSC-часы |
| Data/platform/ | PPU/HDMA, OAM, Super Scope, SPC |
| Data/include/video_layout.h | Адреса VRAM и размеры буферов |
| Data/content/ | Генерируемые текст, таблицы луча, incbin |
| assets/story.json | Единственный редактируемый исходник реплик / точек |
| tools/ | Генерация, проверенная линковка, бюджет памяти, упаковка |
| tools/build_font.py | Чёткий пиксельный ASCII/кириллический шрифт 8×8 |
| tools/build_hero.py, tools/build_torch.py | Кадры героя, точки рук, факел и частицы |
| tools/build_scenery.py | Нативные избы, деревья, колодец и предметы окружения |
| tools/build_npcs.py | Пять жителей 24×36, четыре направления и idle |
| tools/build_backdrop.py | Дальние панорамы и палитры неба/леса |
| tools/perspective_materials.py | Тайловые материалы земли, мха, воды, дерева и камня для Mode 7 |
| tests/ | Ядро, ошибки сборки, прохождение ROM, замер частоты обновлений |

Код отформатирован по `.clang-format`. В рантайме нет heap, float, JSON,
загрузки файлов или случайной генерации карт. Повествование и таблицы лежат
в ROM. Старые intro/menu/over/musicManager из примера не входят в manifest.

## Проверки

После генерации / сборки:

```sh
make -f Makefile.host test
make -f Makefile.host sanitize
python3 -m unittest discover -s tests -p 'test_*.py'
python3 tools/memory_report.py
python3 tests/rom_menu.py --core /path/to/snes9x_libretro.so
python3 tests/rom_story.py --core /path/to/snes9x_libretro.so
python3 tests/rom_story.py --core /path/to/snes9x_libretro.so --pal
python3 tests/rom_splash.py --core /path/to/snes9x_libretro.so
python3 tests/rom_hud.py --core /path/to/snes9x_libretro.so
python3 tests/mesen_video.py --mesen /path/to/Mesen
python3 tests/rom_smoke.py --core /path/to/snes9x_libretro.so --ending secret
python3 tests/rom_smoke.py --core /path/to/snes9x_libretro.so --scope --pal
python3 tests/rom_profile.py --core /path/to/snes9x_libretro.so
python3 tests/rom_scope.py --core /path/to/snes9x_libretro.so
python3 tests/rom_hero.py --core /path/to/snes9x_libretro.so
python3 tests/rom_torch.py --core /path/to/snes9x_libretro.so
python3 tests/rom_daycycle.py --core /path/to/snes9x_libretro.so
python3 tests/rom_combat.py --core /path/to/snes9x_libretro.so
python3 tests/rom_survival.py --core /path/to/snes9x_libretro.so
python3 tests/rom_interaction.py --core /path/to/snes9x_libretro.so
python3 tests/rom_locations.py --core /path/to/snes9x_libretro.so
```

CI выполняет восемь прохождений ROM, шестнадцать регрессий Scope / героя / факела / суток / боя / выживания / взаимодействий / локаций
в PAL и NTSC и проверяет идентичность повторной сборки.
Подробности переноса / измерений — [PORTING.md](docs/PORTING.md),
сценарий — [SCENES.md](docs/SCENES.md), расширение — [EXPANSION.md](docs/EXPANSION.md).
Отчёты генерируются в `build/` и `docs/VALIDATION.md`.

Длительность прохождения после сокращения текста ещё не замерена.
Есть девять звуковых эффектов; нет озвучки, полноценной музыки
и SRAM. Физическая SNES/Scope и macOS не проверены. Результаты эмулятора
не означают гарантированные 60 FPS во всех сценах.

Собственный код / контент — MIT; уведомления SDK, SPC и шрифта —
[THIRD_PARTY.md](docs/THIRD_PARTY.md). Исходные сторонние инструменты и старые
файлы шаблона сохраняют свои уведомления.
