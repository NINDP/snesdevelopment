# Nabla — Тени универа: Проклятие Черноречья

Хоррор для SNES с псевдо‑3D на Mode 7. Продолжение победной концовки `Novgu-Biohazard`:
Кирилл спускается в подвал НовГУ и попадает в тело Всеволода в Черноречье,
1193 год. Нужно вернуть хозяину тела память и найти путь домой.

Сценарий сокращён со 177 до **62 экранов**. Во вступлении события показаны
спортзалом из первой части, проходом по коридору к лестнице, подвалом
и отражением у реки. Между спортзалом и лестницей герой управляется
крестовиной: бег слева направо, семь кадров анимации, плавная прокрутка.
Заставка NABLA TEAM появляется и гаснет; меню повторяет композицию
первой игры с тёмным городом, тёплым светом и пунктами слева.
Обновлены четыре карты, спрайт героя, панели диалогов и свет.
Сохранены 37 групп сцен, загадки, четыре решения и три концовки.

Сюжет — [STORY.md](docs/STORY.md), полный текст — [SCENES.md](docs/SCENES.md).
Исходники графики и промпты — [assets/cinematics/README.md](assets/cinematics/README.md).

## Запуск

Скачай артефакт **chernorechye-snes** из успешной проверки GitHub Actions:
он содержит `chernorechye.sfc`, SHA-256, исходники, сценарий и кадры PPU.
Ветка разработки — `port/chernorechye-snes`. Геймпад — порт 1, Scope — порт 2.
После локальной сборки ROM находится прямо в этой папке.

## Сборка

Нужны Python 3, make, Pillow, NumPy и PVSnesLib **4.6.0**.
Игровой шрифт — собственный пиксельный ASCII/CP1251: системные TTF и
`SK_FONT` для сборки больше не нужны. Упаковка превью использует DejaVu Sans.

```sh
cd SNES_Template
python3 -m pip install -r requirements.txt
sh tools/get_sdk.sh
export PVSNESLIB_HOME="$PWD/third_party/pvsneslib"
make
```

Если SDK уже установлен, достаточно задать `PVSNESLIB_HOME` и вызвать `make`.
Пути к эмулятору и конвертеру в домашней папке не зашиты в Makefile.
Графика / шрифт / BRR и CP1251-текст генерируются инструментами проекта.
Сторонние инструменты в корне репозитория можно использовать для авторинга;
они не являются исполняемым кодом картриджа.

Сборка явно перечисляет C/ASM-модули, отслеживает заголовки до C → .ps,
отклоняет повторяющиеся объекты и проверяет контрольную сумму ROM.
ROM и символы публикуются после успешной линковки; тесты дополнительно
проверяют их хеши по `build/link_manifest.json`.

## Управление

| Действие | Геймпад |
|---|---|
| Идти | Крестовина |
| Включить / выключить свет | X |
| Осмотреть / выбрать / продолжить | A |
| Записи, цель и собранные воспоминания | Y |
| Серебро в исследовании / назад в меню | B |
| Пауза / возврат к порогу | START |

Факел даёт круговой свет с ярким центром, тёплым затемнённым краем
и лёгким мерцанием. В исследовании круг остаётся круглым на экране,
следуя за героем и факелом. За его пределами полностью чёрные и земля,
и персонажи, и предметы. Без факела мир полностью чёрный; диалоги,
журнал и пауза не раскрывают скрытые участки.
Факел держится в левой руке. Есть восемь кадров пламени, локальное свечение
и пять искр с дрейфом и затуханием. Круг света следует за огнём при повороте.
Всеволод — спрайт 32×48: четыре направления, по две позы ожидания
и шесть фаз шага. Для обеих рук сохранены точки крепления предметов
под будущие мечи и луки — [подготовка боя](docs/COMBAT.md).
Отдельный спрайт-лист — assets/generated/torch-sheet.png.
Для осмотра предмет должен быть рядом
и находиться в освещённой области. Смола пополняется у сосудов. Страх возвращает к порогу,
сохраняя решения и находки. Диалоги, меню и головоломки смолу не тратят.

След памяти: держать факел рядом до **45**, затем A. Узел печати: светить до **60**,
затем A. Серебро даёт **три** защитных отклика: отбрасывает тень и снижает страх;
смола и контрольная точка заряды не восстанавливают. Колокола в часовне имеют
отдельную последовательность; объяснение встроено в диалог Авдея.

Scope: первый FIRE/CURSOR или SELECT открывает калибровку. Отпусти кнопку,
затем FIRE по центру белой мишени; CURSOR подтверждает. FIRE задаёт движение / осмотр, CURSOR зажигает факел,
TURBO удерживает героя на месте. Выключи TURBO, чтобы идти.
Журнал и серебро используют Y / B геймпада. Scope требует совместимый CRT;
реальное устройство пока не проверено. Подробности и назначения мыши
для установленного bsnes — [SCOPE.md](docs/SCOPE.md).

## Код и контент

| Путь | Назначение |
|---|---|
| main.c | Вход через GameStart / GameUpdate / GameDraw |
| Data/gameState.c | VBlank, ввод и связь с жизненным циклом шаблона |
| Data/core/ | Переносимое ядро, геометрия света, PAL/NTSC-часы |
| Data/platform/ | PPU/HDMA, OAM, Super Scope, SPC |
| Data/include/video_layout.h | Адреса VRAM и размеры буферов |
| Data/content/ | Генерируемые текст, таблицы луча, incbin |
| assets/story.json | Единственный редактируемый исходник реплик / точек |
| tools/ | Генерация, проверенная линковка, бюджет памяти, упаковка |
| tools/build_font.py | Чёткий пиксельный ASCII/кириллический шрифт 8×8 |
| tools/build_hero.py, tools/build_torch.py | Кадры героя, точки рук, факел и частицы |
| tools/perspective_materials.py | Тайловые материалы земли, мха, воды, дерева и камня для Mode 7 |
| tests/ | Ядро, ошибки сборки, прохождение ROM, замер частоты обновлений |

Код отформатирован по `.clang-format`. В рантайме нет heap, float, JSON,
загрузки файлов или случайной генерации карт. Повествование и таблицы лежат
в ROM. Старые intro/menu/over/musicManager из примера не входят в manifest.

## Проверки

После генерации / сборки:

```sh
make -f Makefile.host test
make -f Makefile.host sanitize
python3 -m unittest discover -s tests -p 'test_build.py'
python3 tools/memory_report.py
python3 tests/rom_smoke.py --core /path/to/snes9x_libretro.so --ending secret
python3 tests/rom_smoke.py --core /path/to/snes9x_libretro.so --scope --pal
python3 tests/rom_profile.py --core /path/to/snes9x_libretro.so
python3 tests/rom_scope.py --core /path/to/snes9x_libretro.so
python3 tests/rom_hero.py --core /path/to/snes9x_libretro.so
python3 tests/rom_torch.py --core /path/to/snes9x_libretro.so
```

CI выполняет восемь прохождений ROM, шесть регрессий Scope / героя / факела
в PAL и NTSC и проверяет идентичность повторной сборки.
Подробности переноса / измерений — [PORTING.md](docs/PORTING.md),
сценарий — [SCENES.md](docs/SCENES.md), расширение — [EXPANSION.md](docs/EXPANSION.md).
Отчёты генерируются в `build/` и `docs/VALIDATION.md`.

Длительность прохождения после сокращения текста ещё не замерена.
Есть три звуковых эффекта; нет озвучки, полноценной музыки
и SRAM. Физическая SNES/Scope и macOS не проверены. Результаты эмулятора
не означают гарантированные 60 FPS во всех сценах.

Собственный код / контент — MIT; уведомления SDK, SPC и шрифта —
[THIRD_PARTY.md](docs/THIRD_PARTY.md). Исходные сторонние инструменты и старые
файлы шаблона сохраняют свои уведомления.
