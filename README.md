# SNES development · Nabla / Черноречье

«Тени универа: Проклятие Черноречья» находится в
[SNES_Template](SNES_Template/README.md). Игра собирается в настоящую
512 KiB LoROM для SNES на PVSnesLib 4.6.0.

Кирилл после победы над Тенью попадает через подвал НовГУ в тело Всеволода.

В игре 37 групп сцен, четыре локации, три концовки,
свет через HDMA, страх, масло, живые тени, следы памяти, серебро, колокола,
журнал и управление геймпадом / Super Scope.

Сборка, управление и проверки — [SNES_Template/README.md](SNES_Template/README.md).
Устройство переноса и бюджеты — [PORTING.md](SNES_Template/docs/PORTING.md).
Сценарий — [SCENES.md](SNES_Template/docs/SCENES.md).

SuperFamiconv, LibreSprite и исходные вспомогательные инструменты сохранены.
Старые демонстрационные состояния остаются как справочный код; их графика,
музыка и объектные файлы не попадают в ROM игры.
